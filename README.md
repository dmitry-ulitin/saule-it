# Saule IT Services — сайт

Статический сайт-визитка на [Astro](https://astro.build) на трёх языках: EN / RU / ET.
На выходе получается обычная папка с HTML, CSS и картинками (`dist/`), которую можно выложить на любой хостинг.

## Быстрый старт

Нужен **Node.js 22.23.4 или новее** (проще всего поставить текущую LTS-версию Node 24 с https://nodejs.org).

```bash
npm install        # один раз: установить зависимости
npm run dev        # режим разработки: http://localhost:4321 , изменения видны сразу
npm run build      # проверка типов + сборка готового сайта в папку dist/
npm run preview    # посмотреть собранный dist/ локально
```

Перед первым запуском скопируйте `.env.example` в `.env` и впишите ключ формы (см. «Контактная форма»).

```
sauleit/
├─ src/                      ← исходники сайта
│  ├─ pages/
│  │  ├─ index.astro         ← "/" — перенаправляет на язык по умолчанию
│  │  ├─ 404.astro           ← страница «не найдено»
│  │  └─ [lang]/             ← каждая страница собирается трижды: /en/…, /ru/…, /et/…
│  │     ├─ index.astro      ← главная
│  │     ├─ services.astro   ← услуги
│  │     ├─ contact.astro    ← контакты
│  │     └─ privacy.astro    ← политика конфиденциальности
│  ├─ i18n/                  ← ВСЕ ТЕКСТЫ САЙТА
│  │  ├─ en.ts  ru.ts  et.ts ← по файлу на язык (заголовки, услуги, SEO title/description…)
│  │  ├─ types.ts            ← структура текстов (TypeScript подскажет, если что-то забыли перевести)
│  │  └─ config.ts           ← список языков, язык по умолчанию, адреса страниц
│  ├─ data/
│  │  ├─ site.ts             ← email, телефон, город — в одном месте
│  │  └─ services.ts         ← порядок услуг, их иконки и фото
│  ├─ components/            ← шапка, подвал, форма, карта, иконки, переключатель языка
│  ├─ layouts/BaseLayout.astro ← общий каркас страницы и SEO: title, description, canonical,
│  │                             hreflang, Open Graph, Schema.org (Organization + ContactPoint)
│  ├─ styles/global.css      ← фирменные цвета (переменные --c-…), шрифт, кнопки
│  └─ assets/images/         ← фото и логотип, которые использует сайт (Astro сам сжимает их в WebP)
├─ public/                   ← файлы «как есть»: favicon, robots.txt, _redirects
├─ astro.config.mjs          ← адрес сайта (SITE_URL), sitemap
├─ docs/                     ← ТЗ, макеты, SEO-чеклист (в сборку не попадают)
├─ brand/                    ← логотип и исходники фото (в сборку не попадают)
└─ dist/                     ← готовый сайт после npm run build (не редактировать, не хранить в git)
```

## Частые правки

| Что нужно | Где |
|---|---|
| Поменять текст на сайте | `src/i18n/en.ts` / `ru.ts` / `et.ts` |
| SEO title и description страниц | там же, раздел `meta` |
| Телефон, email | `src/data/site.ts` |
| Заменить фото услуги | положить новый файл в `src/assets/images/` и поправить импорт в `src/data/services.ts` |
| Цвета | `src/styles/global.css`, блок `:root` |
| Анимация переходов между страницами | `src/styles/transitions.ts` (скорость) и `@keyframes pageIn/pageOut` в `src/styles/global.css` |
| Язык по умолчанию (куда ведёт `/`) | `defaultLocale` в `src/i18n/config.ts` **и** `public/_redirects` |
| Домен | `SITE_URL` в `astro.config.mjs` **и** `public/robots.txt` |

Фото лучше заранее уменьшить до ~1600 px по длинной стороне. Исходники и обработанные версии лежат в `brand/photos/`.

## Контактная форма

Форма отправляет письма через сервис **Web3Forms** — свой сервер не нужен.

1. Зайдите на https://web3forms.com, введите `info@sauleit.com` — ключ придёт на эту почту.
2. Создайте файл `.env` (копия `.env.example`) и впишите `PUBLIC_WEB3FORMS_KEY=ваш-ключ`.
3. На хостинге добавьте ту же переменную в настройках сборки (Environment variables).

Ключ публичный по замыслу сервиса: с ним можно только отправить письмо на ваш же адрес.
В форме есть защита от ботов (скрытое поле `botcheck`); при необходимости в Web3Forms включается hCaptcha.

## Публикация (деплой)

Подойдёт любой статический хостинг. Рекомендация — **Cloudflare Pages** или **Netlify** (бесплатно, HTTPS автоматически):

1. Залейте проект в репозиторий на GitHub (`git init`, затем push).
2. В Cloudflare Pages / Netlify: «New project» → выбрать репозиторий.
3. Настройки сборки: команда `npm run build`, папка `dist`, переменная `NODE_VERSION=24`, переменная `PUBLIC_WEB3FORMS_KEY`.
4. Подключите домен в настройках проекта. После этого каждый push в репозиторий публикует сайт заново.

Файл `public/_redirects` эти хостинги понимают сами: `/` сразу ведёт на `/en/`.

## Аналитика (GA4 + согласие на cookies)

1. В Google Analytics создайте поток данных «Веб» и скопируйте идентификатор вида `G-XXXXXXXXXX`.
2. Впишите его в `.env` как `PUBLIC_GA4_ID=G-…` и добавьте ту же переменную на хостинге.

Пока переменная пустая, аналитика и баннер выключены (сайт не ставит cookies). Когда ID задан, внизу страницы
появляется баннер (`src/components/CookieConsent.astro`, тексты — `cookies` в `src/i18n/*.ts`):

- до нажатия «Принять» скрипт Google не загружается вообще, Consent Mode v2 стоит в `denied`;
- выбор запоминается в браузере; ссылка «Настройки cookies» в подвале открывает баннер снова,
  «Отклонить» отзывает согласие и удаляет cookies `_ga`;
- просмотры страниц отправляются и при плавных переходах между страницами;
- после успешной отправки формы отправляется событие `generate_lead`.

Клики по CTA пока не отслеживаются — у ссылок есть атрибут `data-cta="…"` для этого.
