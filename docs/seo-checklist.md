# SEO-чеклист (по ТЗ «SEO-настройка сайта Saule IT Services»)

Отметки: ✅ сделано в коде · ⏳ сделать при запуске · ❌ ещё не сделано

## 1. Техническое SEO
- ⏳ Google Search Console, отправить sitemap (`/sitemap-index.xml` — генерируется автоматически)
- ✅ `robots.txt` разрешает индексацию и указывает sitemap (`public/robots.txt`; поменять домен)
- ⏳ HTTPS и единый адрес (с www или без) — настраивается на хостинге/у регистратора домена
- ✅ Нет дублей: у каждой страницы `canonical`, все адреса заканчиваются на `/`
- ⏳ 301-редиректы www ↔ без www — на хостинге
- ✅ Мобильная версия; ⏳ проверить скорость и Core Web Vitals (PageSpeed Insights) после публикации

## 2. Мультиязычность (EN / RU / ET)
- ✅ Отдельные индексируемые URL: `/en/…`, `/ru/…`, `/et/…`
- ✅ `hreflang` для всех трёх версий + `x-default` (в `<head>` и в sitemap)
- ✅ Свои Title и Meta Description для каждой версии (`meta` в `src/i18n/*.ts`)
- ✅ Переключатель языков ведёт на ту же страницу на другом языке
- ✅ `<html lang="…">` на каждой странице

## 3. SEO страниц
- ✅ Уникальные Title, Description и один H1 на главной, услугах, контактах
- ✅ Структура заголовков H1 → H2 → H3
- ✅ Понятные URL: `/en/services/`, `/ru/contact/`
- ✅ Внутренние ссылки: главная ↔ услуги ↔ контакты, карточки услуг ведут к нужному разделу (`/ru/services/#banking`)
- ✅ Alt-тексты у содержательных изображений на всех языках

## 4. Поисковая оптимизация услуг
- ✅ Шесть направлений в заголовках H2 на странице услуг и в meta description
- ❌ Подобрать поисковые запросы EN / RU / ET для каждой услуги (Google Keyword Planner, Ahrefs и т.п.) и вписать их в тексты и заголовки
- 💡 Когда появятся запросы — можно сделать отдельную страницу на каждую услугу (`/en/services/banking/`), это сильнее для SEO, чем одна общая

## 5. Структурированные данные
- ✅ Schema.org `ProfessionalService` (подтип Organization) с `ContactPoint` — `src/layouts/BaseLayout.astro`
- ⏳ Телефон появится в разметке автоматически, когда он будет заполнен в `src/data/site.ts`
- ➖ BreadcrumbList — не нужен, пока нет вложенных страниц

## 6. Аналитика
- ❌ GA4 с согласием на cookies (Consent Mode + cookie-баннер)
- ❌ Событие отправки формы (место подготовлено в `ContactForm.astro`)
- ❌ Клики по email и CTA (у ссылок есть атрибут `data-cta`)
- ❌ Проверка событий в GA4 (DebugView)

## 7. Проверка перед запуском
- ⏳ Все три версии доступны для индексации
- ⏳ Sitemap, hreflang, метатеги, мобильная версия
- ⏳ Нет битых ссылок и тестовых страниц в индексе (политика конфиденциальности пока `noindex`, пока это черновик)
- ⏳ После публикации проверить основные URL через Search Console (URL Inspection)
